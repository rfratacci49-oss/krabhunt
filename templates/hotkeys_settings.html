Compteur automatique (resets)

Le programme krabhunt_auto.py regarde une zone de l'écran (émulateur, ou aperçu OBS d'une carte d'acquisition) et compte +1 chaque fois que l'écran de rencontre réapparaît : pratique pour les resets (HGSS…). Il utilise le même fichier krabhunt_raccourcis.json (adresse du site et clé), à placer dans le même dossier.

  1. Une seule fois : pip install mss opencv-python
  2. Calibrer : python krabhunt_auto.py calibrer ho-oh — mettre le jeu sur l'écran de combat, encadrer le cadre nom + PV de l'adversaire, choisir la chasse, régler le seuil pendant un reset d'essai.
  3. Vérifier sans rien envoyer : python krabhunt_auto.py lancer ho-oh --essai
  4. Compter pour de vrai : python krabhunt_auto.py lancer ho-oh (F8 pause si le module keyboard est installé).

La fenêtre du jeu ne doit pas bouger ni être recouverte une fois le profil calibré. Les captures des 50 dernières détections sont gardées pour vérifier qu'il n'y a pas de faux comptage.

Clé d'accès

Le fichier .json contient une clé qui permet de modifier tes compteurs (rien d'autre). Ne la partage pas. Si elle fuit, change-la : l'ancien fichier ne marchera plus.
